訊息傳遞與第二訊息

GPCR、RTK、cAMP/IP3-DAG/Ca²⁺、MAPK 級聯、PI3K-AKT-mTOR——細胞如何「聽見」激素並做出反應。

GPCRs, RTKs, cAMP/IP3-DAG/Ca²⁺, MAPK cascades, PI3K-AKT-mTOR — how cells "hear" hormones and respond.

原則

一、四個原則

🎯 ① 訊息放大

一個激素分子 → 啟動多個 G 蛋白 → 每個 G 蛋白啟動多個 cAMP → 每個 cAMP 啟動多個 PKA → 每個 PKA 磷酸化多個受質。最終放大可達 10⁶ 倍。

One hormone molecule → activates many G proteins → each makes many cAMPs → each activates many PKAs → each phosphorylates many substrates. Net amplification up to 10⁶-fold.

↔️ ② 可逆與終止

磷酸酶移除磷酸；磷酸二酯酶分解 cAMP/cGMP；GTPase 將 G 蛋白關回；β-arrestin 內吞 GPCR。沒有終止 = 病理（如霍亂毒素鎖住 Gs、百日咳毒素鎖住 Gi）。

Phosphatases remove phosphate; PDEs degrade cAMP/cGMP; GTPases switch G proteins off; β-arrestin internalizes GPCRs. No termination = pathology (cholera toxin locks Gs; pertussis toxin locks Gi).

🌐 ③ 整合

同一細胞收多個訊息（hormone, growth factor, ECM, neighbor）——透過交叉抑制/協同形成決策。例如 PI3K-AKT 抑制 mTOR autophagy 但激活 protein 合成。

A single cell integrates many inputs (hormones, growth factors, ECM, neighbors) via cross-inhibition/synergy. PI3K-AKT both inhibits autophagy and activates protein synthesis.

🧮 ④ 特異性

用 scaffolding 蛋白（如 KSR、AKAP）把同路徑酶聚在一起，避免「亂線」。SH2、PTB、PDZ、SH3 結構域辨識磷酸化、PolyPro 序列等，實現精確配對。

Scaffold proteins (KSR, AKAP) keep pathway components together to avoid "crosstalk noise." SH2, PTB, PDZ, SH3 domains read phospho-residues, PolyPro motifs etc. for precise pairing.

GPCR

二、GPCR

人類有 ~800 個 GPCR，是最大的細胞表面受體家族——也是34% 上市藥物的標靶。七次跨膜結構，配體可為光（視紫紅質）、氣味分子、激素、神經傳導物質、肽。

核心機制：配體結合 → 受體構象變 → 內質一側活化 Gα（GDP→GTP 交換）→ Gα 解離後活化下游酶 → GTPase 活性將 Gα 關回 → β-arrestin 招募 → 內吞回收。

三大 Gα 家族與下游：

  • Gαs：激活 adenylyl cyclase → cAMP↑ → PKA。例：β-腎上腺素受體、glucagon 受體
  • Gαi：抑制 adenylyl cyclase → cAMP↓。例：μ-opioid 受體、α2-腎上腺素受體
  • Gαq：激活 PLCβ → IP3 + DAG → Ca²⁺ + PKC。例：α1-腎上腺素、AT1 angiotensin、M1 muscarinic

Humans have ~800 GPCRs — the largest cell-surface receptor family and target of ~34% of approved drugs. Seven-transmembrane structure; ligands include light (rhodopsin), odorants, hormones, neurotransmitters, peptides.

Core mechanism: ligand binds → receptor conformational change → intracellular Gα activation (GDP→GTP) → Gα dissociates to activate downstream enzymes → GTPase activity turns Gα off → β-arrestin recruited → internalization.

Three Gα families and downstream:

  • Gαs: activates adenylyl cyclase → cAMP↑ → PKA. e.g. β-adrenergic, glucagon
  • Gαi: inhibits adenylyl cyclase → cAMP↓. e.g. μ-opioid, α2-adrenergic
  • Gαq: activates PLCβ → IP3 + DAG → Ca²⁺ + PKC. e.g. α1-adrenergic, AT1 angiotensin, M1 muscarinic
💡
2024 GLP-1 革命：GLP-1 受體 (Gαs 路徑) 激動劑（semaglutide / Ozempic, tirzepatide / Mounjaro）。原本為糖尿病藥，後來發現顯著減重效果，2023-2025 在西方掀起減重熱潮。tirzepatide 是 GLP-1 + GIP 雙激動劑，效果更強。下一代正開發口服與三激動劑 (GLP-1 + GIP + glucagon)。 2024 GLP-1 revolution: GLP-1 receptor (Gαs) agonists (semaglutide/Ozempic, tirzepatide/Mounjaro). Originally for diabetes, dramatic weight-loss effects discovered later — 2023-2025 cultural craze in the West. Tirzepatide is a dual GLP-1+GIP agonist; oral and triple-agonist (GLP-1+GIP+glucagon) versions are next.
RTK

三、RTK

~58 個人類 RTK。經典機制：配體誘導二聚化 → 自磷酸化 Tyr → SH2/PTB 接合下游。涵蓋 EGFR (HER family)、insulin R、IGF-1R、VEGFR、PDGFR、FGFR、TRK、Eph 等。

四個主要下游路徑：

  • RAS-RAF-MEK-ERK (MAPK)：增殖、分化。RAS 突變於 ~30% 癌症（KRAS in 結直腸/胰臟/肺）
  • PI3K-AKT-mTOR：細胞存活、生長、代謝。AKT、PI3K、mTOR 突變於多種癌症
  • PLCγ：與 GPCR Gq 路徑匯流：IP3-Ca²⁺、DAG-PKC
  • JAK-STAT：細胞激素受體用此路徑（雖然 JAK 是受體相關激酶，非 RTK 本體）

~58 human RTKs. Core mechanism: ligand-induced dimerization → Tyr autophosphorylation → SH2/PTB recruit downstream. Includes EGFR (HER family), insulin R, IGF-1R, VEGFR, PDGFR, FGFR, TRK, Eph, etc.

Four main downstream paths:

  • RAS-RAF-MEK-ERK (MAPK): proliferation, differentiation. RAS mutated in ~30% of cancers (KRAS in colon/pancreas/lung)
  • PI3K-AKT-mTOR: survival, growth, metabolism. AKT, PI3K, mTOR commonly mutated in cancer
  • PLCγ: converges with Gq path: IP3-Ca²⁺, DAG-PKC
  • JAK-STAT: cytokine receptors (JAK is receptor-associated, not an RTK proper)
