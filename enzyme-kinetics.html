酶動力學與抑制

Michaelis-Menten 方程、kcat/KM、四種抑制模式——藥物作用機制的數學基礎。

Michaelis-Menten, kcat/KM, four inhibition modes — the mathematical foundation of drug action.

MM 方程

一、Michaelis-Menten

1913 Michaelis & Menten 推導：v = Vmax·[S] / (KM + [S])。假設：(1) 酶-基質中間體 ES 在「穩態」存在（Briggs-Haldane 1925）；(2) [S] ≫ [E]，基質消耗可忽略。

關鍵參數：

  • Vmax = kcat·[E]total：酶完全飽和時的速率上限。
  • KM：v 達到 Vmax/2 時的 [S]，反映基質親和力（KM 小 = 親和力高）。
  • kcat (turnover number)：每秒每個酶分子催化的反應次數。範圍：每秒 1 至 10⁷。
  • kcat/KM：「特異性常數」——衡量酶在低基質濃度下的整體效率，上限約 10⁸–10⁹ M⁻¹s⁻¹（擴散極限）。

Michaelis & Menten (1913) derived: v = Vmax·[S] / (KM + [S]). Assumptions: (1) enzyme-substrate ES is in "steady state" (Briggs-Haldane 1925); (2) [S] ≫ [E], so substrate depletion is negligible.

Key parameters:

  • Vmax = kcat·[E]total: max rate at full saturation.
  • KM: [S] at v = Vmax/2; reflects substrate affinity (small KM = high affinity).
  • kcat (turnover): reactions per enzyme per second. Range: 1 to 10⁷ s⁻¹.
  • kcat/KM: "specificity constant" — overall efficiency at low [S]; upper limit ~10⁸–10⁹ M⁻¹s⁻¹ (diffusion limit).
💡
「完美酶 (perfect enzyme)」概念：kcat/KM 接近擴散極限的酶——如 catalase, carbonic anhydrase, triosephosphate isomerase, fumarase——每次擴散到酶口的基質都會被催化。演化已達物理上限。 "Catalytic perfection": enzymes whose kcat/KM reaches the diffusion limit — catalase, carbonic anhydrase, triose phosphate isomerase, fumarase — catalyze virtually every encounter. Evolution has hit the physical ceiling.

⚠️
競爭性抑制可被高基質濃度「克服」（Vmax 不變）；非競爭性與不競爭性無法被克服（Vmax 下降）——這是藥物治療策略的根本差別。例如：methotrexate（競爭性）只在低 folate 時有效，臨床上用 leucovorin 拯救正常細胞。 Competitive inhibition can be overcome by high substrate (Vmax unchanged); non- and uncompetitive cannot (Vmax drops) — a fundamental difference for therapy. Methotrexate (competitive) only works when folate is low; clinically, leucovorin rescues normal cells.
不可逆抑制

三、不可逆抑制

機制：抑制劑與酶形成共價鍵——無法以稀釋或透析逆轉。臨床例子：

  • 阿斯匹靈乙醯化 COX-1/2 的 Ser529/516，永久失活
  • 奧美拉唑 (omeprazole) 與 H⁺/K⁺ ATPase 的 Cys 形成雙硫鍵，停用胃酸分泌
  • 青黴素 (penicillin) 結合細菌 transpeptidase（β-lactam 環打開）
  • Sotorasib (Lumakras, 2021 FDA) ——首個共價 KRAS-G12C 抑制劑，與 Cys12 形成共價鍵
  • Trastuzumab deruxtecan / 共價 EGFR 抑制劑（osimertinib）——新一代抗癌藥物多走共價路線

2020 後熱潮：covalent drug design 強勢回歸——電腦輔助選擇 warhead（acrylamide、α-halocarbonyl）、剖析 cysteinome 找可成藥靶點，covalent fragment screening 成為主要篩選方法。

Mechanism: inhibitor forms a covalent bond with the enzyme — cannot be reversed by dilution or dialysis. Clinical examples:

  • Aspirin acetylates Ser529/516 of COX-1/2, permanently inactivating it
  • Omeprazole forms a disulfide with H⁺/K⁺ ATPase Cys, suppressing acid secretion
  • Penicillin covalently labels bacterial transpeptidase (β-lactam ring opens)
  • Sotorasib (Lumakras, 2021 FDA) — the first covalent KRAS-G12C inhibitor, forms a covalent bond with Cys12
  • Osimertinib (covalent EGFR) — next-gen anticancer drugs increasingly use covalent designs

Post-2020 wave: covalent drug design returns — computational warhead selection (acrylamides, α-halocarbonyls), cysteinome mapping for druggable targets, and covalent fragment screening have become mainstream.

四、判斷抑制類型

🌳 Lineweaver-Burk 診斷

Q1:
所有抑制劑濃度的直線都同樣截 y 軸（1/Vmax 不變）？→ 競爭性抑制。
Q2:
所有直線都同樣截 x 軸（KM 不變）？→ 非競爭性抑制（pure non-competitive）。
Q3:
所有直線互相平行？→ 不競爭性抑制。
Q4:
直線在象限外某點交會？→ 混合型抑制。
Q5:
觀察到時間依賴性 (time-dependent) 抑制？→ 可能是不可逆抑制劑，需做 dilution / dialysis 確認。
Q1:
All lines share the same y-intercept (1/Vmax constant)? → Competitive.
Q2:
All lines share the same x-intercept (KM constant)? → Pure non-competitive.
Q3:
Lines parallel to each other? → Uncompetitive.
Q4:
Lines cross outside both axes? → Mixed inhibition.
Q5:
Time-dependent inhibition observed? → Likely irreversible — confirm by dilution/dialysis.
程式碼

擬合 MM 與 IC50

library(drc)

# 數據：基質濃度 vs 速率
df <- data.frame(
  S = c(5, 10, 20, 50, 100, 200, 500),
  v = c(11, 21, 37, 62, 80, 92, 98)
)

# 非線性最小平方擬合 MM
fit <- drm(v ~ S, data = df, fct = MM.2())
summary(fit)  # 取得 Vmax 與 KM

# IC50：藥物-酶活關係（非 MM）
df2 <- data.frame(
  conc = 10^seq(-9, -4, length.out = 8),
  resp = c(98, 95, 85, 62, 35, 15, 5, 2)
)
ic_fit <- drm(resp ~ conc, data = df2, fct = LL.4(fixed = c(NA, 0, 100, NA)))
ED(ic_fit, 50)  # IC50
import numpy as np
from scipy.optimize import curve_fit
import matplotlib.pyplot as plt

def mm(S, Vmax, KM): return Vmax * S / (KM + S)

S = np.array([5, 10, 20, 50, 100, 200, 500])
v = np.array([11, 21, 37, 62, 80, 92, 98])

popt, pcov = curve_fit(mm, S, v, p0=[100, 50])
Vmax, KM = popt
print(f"Vmax = {Vmax:.1f}, KM = {KM:.1f}")
print(f"kcat/KM (assume [E]=1μM) = {Vmax/KM*1e6:.2e} M⁻¹s⁻¹")

# 4-parameter logistic for IC50
def ll4(c, top, bot, ic50, hill):
    return bot + (top - bot) / (1 + (c/ic50)**hill)

conc = np.logspace(-9, -4, 8)
resp = np.array([98, 95, 85, 62, 35, 15, 5, 2])
popt2, _ = curve_fit(ll4, conc, resp, p0=[100, 0, 1e-6, 1])
print(f"IC50 = {popt2[2]*1e9:.1f} nM")
