生物能量學：ΔG、ATP 與 Redox

熱力學如何驅動生命——能量偶合、redox 電位與「為什麼 ATP 是生命的能量貨幣」。

How thermodynamics drives life — energy coupling, redox potentials, and "why ATP is life's energy currency."

熱力學

一、自由能

反應自發性的判據是吉布斯自由能變化 ΔG，非 ΔH 或 ΔS 單獨。ΔG < 0 = 自發 (exergonic)；ΔG > 0 = 非自發 (endergonic)；ΔG = 0 = 平衡。

關鍵：標準 ΔG°' vs 細胞內 ΔG——標準狀態 (1 M 反應物、pH 7) 的 ΔG°' 與細胞內實際 ΔG 可差很多倍。許多書上「ATP 水解 ΔG°' = −30.5 kJ/mol」是標準狀態；細胞內因為 ATP/ADP 比例約 100，實際 ΔG ≈ −50 至 −65 kJ/mol。

ΔG = ΔG°' + RT ln(Q)，Q = 反應商 = [products]/[reactants]。這個方程是理解能量偶合的關鍵。

The criterion for spontaneity is Gibbs free-energy change ΔG, not ΔH or ΔS alone. ΔG < 0 = spontaneous (exergonic); ΔG > 0 = non-spontaneous (endergonic); ΔG = 0 = equilibrium.

Key: standard ΔG°' vs cellular ΔG — the textbook ΔG°' (1 M reactants, pH 7) often differs greatly from cellular ΔG. The famous "ATP hydrolysis ΔG°' = −30.5 kJ/mol" is the standard value; in cells, the ATP/ADP ratio ~100 pushes actual ΔG to −50 to −65 kJ/mol.

ΔG = ΔG°' + RT ln(Q), where Q = [products]/[reactants]. This equation is the key to understanding energy coupling.

💡
能量偶合 (energy coupling)：把熱力學不利的反應與大量釋能反應「綁在一起」，使總 ΔG < 0。例如：胺基酸活化（ΔG°' = +14 kJ/mol，不利） + ATP 水解 (−30.5) = −16.5 kJ/mol（自發）。沒有偶合，生命根本無法合成任何東西。 Energy coupling: linking a thermodynamically unfavorable reaction with an exergonic one so that net ΔG < 0. Example: amino-acid activation (ΔG°' = +14, unfavorable) + ATP hydrolysis (−30.5) = −16.5 kJ/mol (spontaneous). Without coupling, life could not biosynthesize anything.
ATP

二、為什麼是 ATP？

三磷酸腺苷的「高能磷酸鍵」其實是個誤導——磷酸酐鍵本身不是不尋常的化學鍵。ATP 水解 ΔG°' 之所以特別大（−30.5 kJ/mol）來自三個因素：

  1. 電荷排斥釋放：三個磷酸基帶 4 個負電，水解後一分為二減輕排斥
  2. 共振穩定：產物 ADP³⁻ 和 Pi²⁻ 的共振結構數量遠多於 ATP⁴⁻
  3. 水合改善：分開後產物與水形成更多氫鍵

細胞內 ATP 濃度：~2–10 mM；ADP ~10–50 μM；AMP ~0.5–5 μM。ATP/ADP 比例維持在 100–1000，所以實際 ΔG 比 ΔG°' 大得多。

The "high-energy phosphate bond" is somewhat misleading — phosphoanhydride bonds aren't chemically unusual. ATP hydrolysis ΔG°' is large (−30.5 kJ/mol) for three reasons:

  1. Charge repulsion relief: ATP's three phosphates carry 4 negative charges; splitting reduces repulsion
  2. Resonance stabilization: products (ADP³⁻ and Pi²⁻) have many more resonance structures than ATP⁴⁻
  3. Better hydration: products form more H-bonds with water

Cellular ATP: ~2–10 mM; ADP ~10–50 μM; AMP ~0.5–5 μM. The ATP/ADP ratio (100–1000) makes cellular ΔG much larger than ΔG°'.

⚠️
關鍵概念：ATP 是「中間能量」化合物——能量比上方化合物低（接受其磷酸），但比下方高（可轉移磷酸給葡萄糖、AA、核苷酸）。這個「中間性」讓它成為理想的能量幣。 Key concept: ATP is an intermediate-energy compound — lower than the compounds above (it accepts phosphate from them), higher than those below (it donates phosphate to glucose, AAs, nucleotides). This intermediacy makes it the ideal currency.
Redox

三、Redox 電位

氧化還原反應的方向由半反應的標準電位 E°' 決定。電子自低電位（高還原力）流向高電位（強氧化）。連結 ΔG°' 與 ΔE°' 的公式：

ΔG°' = −n F ΔE°'

其中 n = 電子數、F = 法拉第常數 (96.485 kJ/V·mol)。NADH (E°' = −0.32 V) 將電子傳給 O₂ (E°' = +0.82 V)，ΔE°' = 1.14 V，每 NADH 釋放 220 kJ/mol——足以合成多個 ATP。

Direction of redox is set by the standard reduction potentials E°'. Electrons flow from low potential (strong reductant) to high potential (strong oxidant). Linking ΔG°' to ΔE°':

ΔG°' = −n F ΔE°'

where n = electrons, F = Faraday constant (96.485 kJ/V·mol). NADH (E°' = −0.32 V) → O₂ (E°' = +0.82 V), ΔE°' = 1.14 V, releasing 220 kJ/mol per NADH — enough to make several ATPs.

四、偶合策略

🌳 如何驅動 endergonic 反應？

Q1:
反應 ΔG°' < +30 kJ/mol？→ 偶合一個 ATP 水解（−30 kJ/mol）足夠。
Q2:
反應 ΔG°' 介於 +30 到 +60？→ 偶合兩個 ATP（如核苷酸 PRPP 合成）。
Q3:
反應 ΔG°' > +60？→ 通常用能量更高的 PEP、磷酸肌酸、GTP，或多次 ATP（脂肪酸合成每延長 2 碳消耗 ATP+NADPH）。
Q4:
不能直接偶合 ATP 的反應？→ 用 離子梯度偶合（如 ATP synthase 利用 H⁺ 梯度合成 ATP；SGLT 用 Na⁺ 梯度進葡萄糖）。
Q5:
需要還原力？→ 用 NADPH（脂肪酸合成、核苷酸合成、ROS 抗氧化）；而非 NADH（用於分解產 ATP）。
Q1:
Reaction ΔG°' < +30 kJ/mol? → Coupling one ATP hydrolysis (−30 kJ/mol) suffices.
Q2:
ΔG°' between +30 and +60? → Use two ATPs (e.g. PRPP synthesis).
Q3:
ΔG°' > +60? → Use higher-energy compounds (PEP, phosphocreatine, GTP) or multi-step ATP coupling (FA synthesis uses ATP+NADPH per 2C extension).
Q4:
Cannot directly couple ATP? → Use ion-gradient coupling (ATP synthase couples H⁺ gradient; SGLT uses Na⁺ gradient to import glucose).
Q5:
Need reducing power? → Use NADPH (FA synthesis, nucleotide synthesis, antioxidant), not NADH (used for catabolism/ATP).
程式碼

ΔG 計算

# ΔG = ΔG°' + RT ln(Q)
delta_G <- function(dG0_prime, Q, T = 310) {
  R <- 8.314e-3  # kJ/(mol·K)
  dG0_prime + R * T * log(Q)
}

# 細胞內 ATP 水解（ATP=4mM, ADP=0.04mM, Pi=4mM）
Q_ATP <- (0.04 * 4) / 4  # [ADP][Pi]/[ATP]
delta_G(-30.5, Q_ATP)  # ≈ -57 kJ/mol（細胞內遠比 -30.5 大）

# 從 redox 電位算 ΔG
deltaG_redox <- function(dE_prime, n) {
  F <- 96.485  # kJ/(V·mol)
  -n * F * dE_prime
}
# NADH → O2: ΔE°' = 1.14 V, n = 2
deltaG_redox(1.14, 2)  # -220 kJ/mol

# 能量電荷 (Atkinson 能量電荷)
energy_charge <- function(ATP, ADP, AMP) {
  (ATP + 0.5 * ADP) / (ATP + ADP + AMP)
}
energy_charge(5, 0.5, 0.05)  # 健康細胞 ~ 0.85-0.95
import numpy as np

R = 8.314e-3  # kJ/(mol·K)
F = 96.485    # kJ/(V·mol)

def delta_G(dG0, Q, T=310):
    return dG0 + R * T * np.log(Q)

# ATP 在細胞 vs 標準
print(f"Cellular ATP ΔG ≈ {delta_G(-30.5, 0.04*4/4):.1f} kJ/mol")
print(f"Standard ATP ΔG°' = -30.5 kJ/mol")

# Redox: NADH → O2
dG_redox = -2 * F * 1.14
print(f"NADH→O2 ΔG°' = {dG_redox:.0f} kJ/mol")

# 能量電荷
def energy_charge(ATP, ADP, AMP):
    return (ATP + 0.5*ADP) / (ATP + ADP + AMP)

# 多種細胞狀態
states = {
    "健康細胞": (5, 0.5, 0.05),
    "運動疲憊": (2, 2, 0.5),
    "缺氧/瀕死": (0.5, 2, 3),
}
for state, (a,d,m) in states.items():
    print(f"{state}: EC = {energy_charge(a,d,m):.2f}")
# EC < 0.5 → 細胞凋亡 / 自噬訊號
