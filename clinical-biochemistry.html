臨床生化與代謝疾病

糖尿病、痛風、PKU、粒線體病——生化路徑出錯如何造成疾病；常規血液檢驗背後的化學。

Diabetes, gout, PKU, mitochondrial disease — how broken pathways cause disease, and the chemistry behind routine blood tests.

糖尿病

一、糖尿病

Type 1Type 2MODY/單基因妊娠
病因自體免疫阻抗 + 衰退單基因暫時
治療胰島素多藥磺脲飲食
HbA1c<7.0%<7.0%<6.5%<6.5%

糖化血色素 (HbA1c)：葡萄糖透過非酶 Maillard 反應共價接到血紅蛋白 N 末端 Val。因為紅血球壽命約 120 天，HbA1c 反映過去 8-12 週的平均血糖。< 5.7% 正常，5.7-6.4% 前期，> 6.5% 糖尿病。

糖尿病併發症的化學：持續高血糖造成蛋白糖化 (AGEs)——蛋白功能受損，血管、神經、腎、視網膜逐漸受害。GLO1（甘油醛 lyase）解毒系統一旦力不從心，臨床併發症出現。

HbA1c (glycated hemoglobin): glucose covalently attaches to hemoglobin N-terminal Val via non-enzymatic Maillard reaction. RBC lifespan ~120 days → HbA1c reflects 8-12 week average blood glucose. <5.7% normal, 5.7-6.4% prediabetes, >6.5% diabetes.

Chemistry of diabetic complications: chronic hyperglycemia causes protein glycation → AGEs — impaired function in vessels, nerves, kidneys, retinas. When the GLO1 (glyoxalase) detox system is overwhelmed, complications emerge.

先天代謝缺陷

二、IEM 經典案例

🧪 PKU

PAH 缺陷無法把 Phe 轉成 Tyr → Phe 累積（>1 mM）→ 神經毒性、智能障礙。新生兒篩檢標準項目。治療：嚴格低 Phe 飲食 + Tyr 補充。2024 新藥：sepiapterin (BH4 增益)、pegvaliase (PAL 酶替代)。

PAH deficiency blocks Phe → Tyr → Phe accumulates (>1 mM) → neurotoxicity, intellectual disability. Standard newborn screen item. Treatment: low-Phe diet + Tyr. 2024 drugs: sepiapterin (BH4 augmenter), pegvaliase (enzyme replacement).

🍼 半乳糖血症

GALT 缺陷 → 半乳糖累積、肝損傷、白內障、智能。新生兒篩檢。治療：終身無乳糖飲食。

GALT deficiency → galactose accumulates, causing liver damage, cataracts, intellectual disability. Newborn-screened. Treatment: lifelong lactose-free diet.

🧬 鐮刀型貧血

HbS：β-globin Glu6Val 突變 → 缺氧時聚合形成纖維 → RBC 變形。2023 FDA：Casgevy，CRISPR-Cas9 治療鐮刀症的首個基因編輯藥物。

HbS: β-globin Glu6Val → deoxy-state polymerizes into fibers → RBC sickling. 2023 FDA: Casgevy, the first CRISPR-Cas9 therapy, approved for sickle cell.

🦠 囊狀纖維化

CFTR (氯離子通道) 缺陷——ΔF508 最常見。引發濃稠黏液阻塞肺與胰。Trikafta (2019)：elexacaftor + tezacaftor + ivacaftor 三藥組合，矯正蛋白摺疊與通道功能，大幅改善預後。

CFTR (Cl⁻ channel) defect — ΔF508 most common. Thick mucus blocks lungs and pancreas. Trikafta (2019): elexacaftor + tezacaftor + ivacaftor — corrects folding + restores channel function; transformed prognosis.

🩺 楓糖尿症

BCKDH 缺陷 → 分支鏈胺基酸 (Leu/Ile/Val) 與支酮酸累積 → 尿有楓糖味。新生兒嗜睡、抽搐。治療：嚴格 BCAA 飲食 + 急性高蛋白移除。

BCKDH defect → BCAAs (Leu/Ile/Val) + branched ketoacids accumulate → urine smells like maple syrup. Neonatal lethargy, seizures. Treatment: strict BCAA-restricted diet + acute removal of protein.

⚡ 粒線體病

mtDNA 或核 DNA 編碼的 ETC/TCA/PDH 蛋白突變。臨床多樣：MELAS（中風樣發作）、LHON（視神經）、Leigh（嬰兒神經退化）、MERRF（肌陣攣性癲癇）。2025 新藥: vincerinone (Leigh)、elamipretide (心肌粒線體疾病) 臨床測試中。

mtDNA or nuclear-encoded ETC/TCA/PDH mutations. Heterogeneous: MELAS (stroke-like), LHON (optic), Leigh (infantile neurodegeneration), MERRF (myoclonic epilepsy). 2025: vincerinone (Leigh), elamipretide (cardiac mito) in trials.

痛風

三、痛風

嘌呤代謝終產物為尿酸。人類缺乏尿酸氧化酶（基因失活），所以尿酸是最終代謝物。血漿尿酸 > 6.8 mg/dL 即接近溶解度上限，過量時形成單水尿酸鈉晶體 (MSU) 沉積關節，引發劇痛炎症（NLRP3 inflammasome 激活）。

臨床治療：

  • 急性: NSAIDs (阻斷 COX/前列腺素)、秋水仙素 (colchicine)、類固醇
  • 慢性降尿酸: allopurinol、febuxostat（黃嘌呤氧化酶抑制劑，阻止尿酸生成）
  • 溶解尿酸: pegloticase（重組尿酸氧化酶，僅難治型）

End product of purine catabolism is urate. Humans lack urate oxidase (gene inactivated), so urate is the terminal metabolite. Plasma urate > 6.8 mg/dL approaches its solubility limit; excess crystallizes as monosodium urate (MSU) in joints, triggering severe inflammation (NLRP3 inflammasome activation).

Clinical treatment:

  • Acute: NSAIDs (block COX/PG), colchicine, steroids
  • Chronic urate-lowering: allopurinol, febuxostat (xanthine oxidase inhibitors)
  • Urate degradation: pegloticase (recombinant urate oxidase, refractory cases only)

決策引導

五、新生兒急症

🌳 代謝急症診斷

血氨 ↑→
尿素循環缺陷（OTC、CPS-1、ASS、ASL）或有機酸血症（B12 相關）。緊急血液透析。
低血糖→
糖原儲積病（GSD I, von Gierke）、脂肪酸氧化缺陷（MCAD）、糖質新生缺陷。
代謝性酸中毒→
查 anion gap：若高，可能是有機酸尿、乳酸性酸中毒（粒線體病）、酮酸中毒（MSUD、DKA）。
尿味異常→
楓糖尿味 = MSUD；鼠尿味 = PKU；汗腳味 = 異戊酸血症
家族史→
近親結婚、過去新生兒死亡——疑似 X 連鎖或常染色體隱性 IEM。
High ammonia→
Urea cycle defect (OTC, CPS-1, ASS, ASL) or organic acidemia (B12-related). Emergency dialysis.
Hypoglycemia→
Glycogen storage disease (GSD I, von Gierke), FA oxidation defect (MCAD), gluconeogenesis defect.
Metabolic acidosis→
Check anion gap: if elevated, consider organic aciduria, lactic acidosis (mito disease), ketoacidosis (MSUD, DKA).
Abnormal urine odor→
Maple syrup = MSUD; mousy = PKU; sweaty-feet = isovaleric acidemia
Family history→
Consanguinity, prior neonatal death — suspect X-linked or autosomal recessive IEM.
程式碼

HbA1c 與 eAG

# Nathan formula (ADAG 2008): eAG (mg/dL) = 28.7 × HbA1c − 46.7
hba1c_to_eag <- function(a1c) 28.7 * a1c - 46.7

# 範例
hba1c <- c(5.0, 5.7, 6.5, 7.0, 8.0, 9.0)
data.frame(HbA1c=hba1c, eAG_mgdl=hba1c_to_eag(hba1c))

# 計算 eGFR (CKD-EPI 2021)
egfr_ckdepi <- function(Scr, age, female, race=NULL) {
  # Scr in mg/dL; 2021 不再用 race 校正
  kappa <- ifelse(female, 0.7, 0.9)
  alpha <- ifelse(female, -0.241, -0.302)
  egfr <- 142 * min(Scr/kappa, 1)^alpha * max(Scr/kappa, 1)^-1.200 *
          0.9938^age * ifelse(female, 1.012, 1)
  egfr
}
egfr_ckdepi(1.5, 65, FALSE)  # 中度 CKD
def hba1c_to_eag(a1c):

# Lipid panel risk stratification (ASCVD 10-year risk calculator)
def ldl_target(risk_category):
    targets = {
        "very_high": 70,     # 確診冠心、糖尿病 + 風險因子
        "high":      100,
        "moderate":  130,
        "low":       160,
    }
    return targets[risk_category]

# 肝功能評估 - 大致用 ALT 與 AST 比例
def ast_alt_ratio(AST, ALT):
    ratio = AST / ALT
    if ratio > 2: return "Alcoholic hepatitis"
    elif ratio > 1.5: return "Cirrhosis (advanced)"
    elif ratio < 1: return "Viral hepatitis / NAFLD"
    else: return "Nonspecific"

print(ast_alt_ratio(80, 30))  # 酒精
