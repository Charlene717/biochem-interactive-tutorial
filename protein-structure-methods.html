結構解析方法與 AlphaFold 3

從 X-ray 到 cryo-EM 原子解析，從 AlphaFold 2 到 AlphaFold 3 涵蓋核酸與配體——2026 結構生物學的全景。

From X-ray to atomic cryo-EM, from AlphaFold 2 to AlphaFold 3 covering nucleic acids and ligands — the 2026 landscape of structural biology.

概覽

為什麼要解結構？

結構是機制 (mechanism) 的鑰匙。沒有結構，我們只能從動力學、突變、生化反應推測酶/受體如何作用；有了結構，就能直接看見：催化殘基如何排列、藥物如何結合、變構訊號如何傳遞、突變為何致病。

PDB（Protein Data Bank）截至 2026 已收錄超過 230,000 個實驗結構與 AlphaFold DB 約 2 億預測模型——涵蓋幾乎所有已知蛋白序列。

Structure is the key to mechanism. Without structures, we can only infer enzyme/receptor function from kinetics, mutations, and indirect biochemistry; with structures, we directly see how catalytic residues align, how drugs bind, how allosteric signals propagate, and why mutations cause disease.

By 2026 the Protein Data Bank holds >230,000 experimental structures, and the AlphaFold DB ~200 million predicted models — covering essentially every known protein sequence.

In 2025, microsecond time-resolved cryo-EM (laser flash-melting + revitrification) enabled the first direct snapshots of "enzyme-reaction intermediates."
AlphaFold 3

二、AlphaFold 3

AlphaFold 2 (2020) 革新蛋白質結構預測；但僅能處理蛋白。AlphaFold 3 (Abramson et al., Nature 2024) 將架構擴展到蛋白質-蛋白質、蛋白質-核酸、蛋白質-小分子配體、蛋白質-離子、修飾胺基酸的聯合預測，核心改為擴散模型 (diffusion network)。

關鍵突破：

  • 蛋白-配體預測準確度比傳統 docking 提升 ~50%（PoseBusters benchmark）
  • 蛋白-核酸複合物比專門核酸預測器更準
  • 抗體-抗原預測準確度大幅高於 AlphaFold-Multimer v2.3
  • 毋需輸入任何結構資訊，從序列直接預測複合物

AlphaFold 2 (2020) revolutionized protein structure prediction but handled proteins only. AlphaFold 3 (Abramson et al., Nature 2024) extends the architecture to jointly predict protein–protein, protein–nucleic-acid, protein–small-molecule, protein–ion, and modified-residue complexes. The core moved to a diffusion network.

Key advances:

  • Protein–ligand accuracy ~50% higher than traditional docking (PoseBusters benchmark)
  • Protein–nucleic-acid complexes outperform specialized predictors
  • Antibody–antigen accuracy far exceeds AlphaFold-Multimer v2.3
  • No structural input needed — predicts complexes directly from sequence
⚠️
AlphaFold 3 的限制：(1) 對 IDP/未摺疊區、構象集合的描述仍弱；(2) 變構效應與配體誘發構象變化未必準確；(3) 預測 RMSD 並不等同於可信度——應檢查 pLDDT 與 PAE 分數；(4) 共價修飾、稀有金屬中心、糖鏈仍是相對弱項。實驗結構仍是金標準。 AlphaFold 3 limits: (1) Poor on IDPs/unfolded regions and conformational ensembles; (2) Allosteric effects and ligand-induced conformational change are not always accurate; (3) RMSD ≠ confidence — always check pLDDT and PAE; (4) Covalent modifications, rare metal centers, glycan chains are relative weak spots. Experimental structures remain the gold standard.

三、解析路徑選擇

🌳 實驗 vs 預測

Q1:
你需要的是機制細節還是整體摺疊預判？→ 機制 = 實驗結構；整體預判 = AlphaFold 3 即可。
Q2:
蛋白能結晶嗎？→ 能 = X-ray（解析度可達 1 Å）；不能 = cryo-EM（≥50 kDa）或 NMR（≤30 kDa）。
Q3:
研究膜蛋白嗎？→ 首選 cryo-EM in nanodiscs/SMA；2025 後絕大多數 GPCR 結構都用 cryo-EM。
Q4:
研究 IDP / 動態？→ NMR (HSQC、relaxation) 或 SAXS + EPR；AlphaFold 對動態幾乎無效。
Q5:
需要看「反應中間態」？→ Time-resolved X-ray (XFEL) 或 microsecond cryo-EM（2025 起可用）。
Q1:
Do you need mechanistic detail or just a rough fold? → Mechanism = experimental; rough fold = AlphaFold 3 is enough.
Q2:
Crystallizable? → Yes = X-ray (down to 1 Å); No = cryo-EM (≥50 kDa) or NMR (≤30 kDa).
Q3:
Membrane protein? → Cryo-EM in nanodiscs/SMA; nearly all post-2025 GPCR structures use cryo-EM.
Q4:
IDP / dynamics? → NMR (HSQC, relaxation) or SAXS + EPR; AlphaFold is essentially blind to dynamics.
Q5:
Need reaction intermediates? → Time-resolved X-ray (XFEL) or microsecond cryo-EM (available since 2025).
程式碼

AlphaFold + PDB

library(bio3d)

# 從 PDB 下載結構
pdb <- read.pdb("1HHO")  # 血紅蛋白

# 基本資訊
summary(pdb)
torsion.pdb(pdb)$phi  # Ramachandran φ

# 比對兩個結構（如 AlphaFold 預測 vs 實驗）
af_pdb <- read.pdb("AF-P69905-F1-model_v4.pdb")
aln <- struct.aln(pdb, af_pdb)
cat("RMSD =", aln$rmsd, "Å\n")

# 標記 pLDDT 高/低區（AlphaFold 信心分數）
plddt <- af_pdb$atom$b[af_pdb$atom$elety == "CA"]
hist(plddt, breaks=50, main="AlphaFold pLDDT")
# pLDDT > 90: 非常可信；70-90: 可信主鏈；50-70: 低信心；<50: 通常無序
from Bio.PDB import PDBParser, Superimposer
import numpy as np

parser = PDBParser(QUIET=True)
exp = parser.get_structure("hb", "1HHO.pdb")
af  = parser.get_structure("af", "AF-P69905-F1-model_v4.pdb")

# 蒐集 CA 原子作疊合
exp_ca = [a for a in exp.get_atoms() if a.name=="CA"]
af_ca  = [a for a in af.get_atoms()  if a.name=="CA"]

sup = Superimposer()
sup.set_atoms(exp_ca[:len(af_ca)], af_ca[:len(exp_ca)])
print(f"RMSD = {sup.rms:.2f} Å")

# 讀 pLDDT（存放在 B-factor 欄位）
plddt = np.array([a.get_bfactor() for a in af_ca])
print(f"Mean pLDDT: {plddt.mean():.1f}")
print(f"% confident (>70): {(plddt>70).mean()*100:.1f}%")

# API 呼叫 ESM-Fold / AlphaFold Server (2024+)
import requests
seq = "MKTLLLTLVVVTIVCLDLGYT..."
r = requests.post("https://api.esmatlas.com/foldSequence/v1/pdb/", data=seq)
with open("esm.pdb", "w") as f: f.write(r.text)
