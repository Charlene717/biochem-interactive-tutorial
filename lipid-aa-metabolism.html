脂質與胺基酸代謝

β 氧化、脂肪酸合成、酮體、轉胺反應、尿素循環——身體燃料、骨架與廢物處理的化學。

β-oxidation, fatty-acid synthesis, ketone bodies, transamination, urea cycle — the chemistry of fuel, building blocks, and waste.

β-氧化

一、β 氧化

脂肪酸分解的核心過程，發生在粒線體基質。每輪移除 2 個碳產出一個乙醯-CoA。

3 個關鍵步驟：(1) 脂肪酸 + CoA 在細胞質活化為脂醯-CoA (耗 2 ATP)；(2) 肉鹼穿梭 (carnitine shuttle) 將長鏈脂醯帶過內膜（受 malonyl-CoA 抑制——這是脂解 vs 脂合的關鍵切換點）；(3) 基質內進入 β-氧化 4 步循環：脫氫 (FAD)→水合→脫氫 (NAD)→硫解。

能量產率：例如 16 碳棕櫚酸完全氧化產 106 ATP（vs 葡萄糖 30 ATP/6C =每碳 5 ATP，脂肪酸每碳 ~6.6 ATP）。所以脂肪是「最划算」能量儲存——每克 9 kcal vs 葡萄糖 4 kcal。

The core fat-breakdown pathway in the mitochondrial matrix. Each cycle removes 2 carbons producing one acetyl-CoA.

3 critical steps: (1) cytosolic activation: FA + CoA → fatty acyl-CoA (costs 2 ATP); (2) carnitine shuttle to cross inner membrane (inhibited by malonyl-CoA — the lipogenesis/lipolysis switch); (3) β-oxidation 4-step cycle in matrix: dehydrogenation (FAD) → hydration → dehydrogenation (NAD) → thiolysis.

Energy yield: e.g. palmitate (16C) fully oxidized → 106 ATP. Glucose: 30 ATP/6C = 5 per C; fat ~6.6 per C. Fat is the most efficient energy storage — 9 kcal/g vs 4 kcal/g for sugars.

💡
Malonyl-CoA 的雙重角色：(1) 脂肪酸合成第一個中間體；(2) 抑制 CPT-1（肉鹼穿梭），阻止脂肪酸進粒線體燃燒。這個分子是「身體決定是要合脂還是燒脂」的關鍵開關，受 ACC (acetyl-CoA carboxylase) 調控，後者再受 AMPK 與胰島素影響。 Malonyl-CoA's dual role: (1) first intermediate of FA synthesis; (2) inhibits CPT-1 (carnitine shuttle), blocking FA entry into mitochondria for oxidation. This molecule is the switch deciding "synthesize or burn fat" — controlled by ACC (acetyl-CoA carboxylase), itself regulated by AMPK and insulin.

FA 合成

二、脂肪酸合成

發生在細胞質（不是粒線體！）。乙醯-CoA 需經 citrate 從粒線體運出（citrate shuttle），再被 ACC 羧化為 malonyl-CoA。脂肪酸合成酶 (FAS) 是大型多功能酶（哺乳類為單一蛋白質帶 7 個催化結構域），每輪延長 2 碳，消耗1 malonyl-CoA + 2 NADPH。

對比 β 氧化：不同位置（質 vs 基質）、不同還原力（NADPH vs NADH/FAD）、不同活化（malonyl-CoA 與 acyl carrier protein vs CoA），確保兩者不會同時跑——避免「無效循環」。

Occurs in the cytoplasm (not mitochondria!). Acetyl-CoA exits mitochondria via citrate shuttle, then ACC carboxylates it to malonyl-CoA. Fatty acid synthase (FAS) is a large multifunctional enzyme (in mammals, one protein with 7 catalytic domains). Each round extends 2 carbons, consuming 1 malonyl-CoA + 2 NADPH.

Versus β-oxidation: different location (cytosol vs matrix), different reducing power (NADPH vs NADH/FAD), different activation (malonyl-CoA + ACP vs CoA) — preventing a futile cycle.

酮體

三、酮體

長期飢餓或控制不佳的糖尿病：肝臟大量 β 氧化 → acetyl-CoA 過剩 → 無 OAA（被糖質新生抽走）→ TCA 卡住 → 乙醯-CoA 改路徑合成酮體（乙醯乙酸、β-羥丁酸、丙酮）。

酮體是水溶性、能跨血腦屏障——飢餓時 50% 大腦能量來自酮體（神經元無法燒脂肪酸）。酮體被周邊組織轉回 acetyl-CoA 進入 TCA。

糖尿病酮酸中毒 (DKA)：第一型糖尿病典型急症——胰島素缺乏導致脂解過度、酮體過剩、血液 pH 急降（<7.3）。臨床表現：脫水、Kussmaul 呼吸（深快）、酮味呼氣、意識模糊。

2024 熱：生酮飲食用於癲癇（兒童難治性療法）、神經退化病、減重——機制涉及酮體作為訊息分子 (HCA2 受體、HDAC 抑制)。

Prolonged starvation or uncontrolled diabetes: liver high β-oxidation → excess acetyl-CoA → OAA depleted (taken by gluconeogenesis) → TCA stalls → acetyl-CoA reroutes to ketone bodies (acetoacetate, β-hydroxybutyrate, acetone).

Ketone bodies are water-soluble and cross the blood-brain barrier — fuel ~50% of brain energy during starvation (neurons can't use FAs). Peripheral tissues convert them back to acetyl-CoA for TCA.

Diabetic ketoacidosis (DKA): classic type-1 diabetes emergency — insulin deficiency → excessive lipolysis → ketone overproduction → blood pH crashes (<7.3). Clinically: dehydration, Kussmaul breathing (deep/fast), "acetone breath," confusion.

2024 trend: ketogenic diet for epilepsy (refractory pediatric), neurodegeneration, weight loss — mechanisms include ketones as signaling molecules (HCA2 receptor, HDAC inhibition).

胺基酸代謝

四、胺基酸代謝

胺基酸的命運：(1) 蛋白質合成；(2) 轉胺脫氨後骨架進代謝；(3) 合成神經傳導物質 (Trp→serotonin、Tyr→dopamine/epinephrine、Glu→GABA)、血基質、嘌呤/嘧啶。

轉胺反應：胺基轉到 α-酮戊二酸生成麩胺酸，由 PLP（B6 衍生輔因子）介導。ALT/AST（肝功能標誌）就是這類酶。

尿素循環：把 NH₃ 變成 urea 排出（過量氨對神經有毒）。5 步：carbamoyl-P 合成 (CPS-I, 粒線體) → ornithine + carbamoyl-P → citrulline → argininosuccinate → arginine → urea + ornithine。每生成 1 urea 消耗 4 ATP eq。

胺基酸分類：

  • 純醣原性：Ala, Gly, Ser, Cys, Asp, Asn, Glu, Gln, Pro, Met, His, Val, Arg
  • 純酮原性：Lys, Leu
  • 兩者皆是：Trp, Phe, Tyr, Thr, Ile

Fates of amino acids: (1) protein synthesis; (2) transaminate/deaminate then skeleton enters metabolism; (3) make neurotransmitters (Trp→serotonin, Tyr→dopamine/epinephrine, Glu→GABA), heme, purines/pyrimidines.

Transamination: amino group transferred to α-KG → glutamate, mediated by PLP (a vitamin-B6 cofactor). ALT/AST (liver function biomarkers) are such enzymes.

Urea cycle: converts ammonia to urea (excess ammonia is neurotoxic). 5 steps: carbamoyl-P synthesis (CPS-I, mitochondrial) → ornithine + carbamoyl-P → citrulline → argininosuccinate → arginine → urea + ornithine. 4 ATP-equivalents consumed per urea.

AA classification:

  • Purely glucogenic: Ala, Gly, Ser, Cys, Asp, Asn, Glu, Gln, Pro, Met, His, Val, Arg
  • Purely ketogenic: Lys, Leu
  • Both: Trp, Phe, Tyr, Thr, Ile
⚠️
尿素循環缺陷：各步酶缺陷都會造成高血氨症（OTC 缺陷最常見、X 連鎖）。臨床表現：新生兒嗜睡、抽搐、昏迷——若未及時處理可致命。處理：低蛋白飲食、移除氨（lactulose、phenylbutyrate）、必要時血液透析。 Urea cycle defects: deficiencies in any step cause hyperammonemia (OTC deficiency is most common; X-linked). Clinically: neonatal lethargy, seizures, coma — can be fatal without prompt treatment. Manage with low-protein diet, ammonia scavengers (lactulose, phenylbutyrate), and dialysis if needed.

FA 氧化能量計算

# 計算飽和脂肪酸完全氧化 ATP 產量
fa_atp <- function(n_carbons) {
  cycles <- (n_carbons / 2) - 1
  acetyl_CoA <- n_carbons / 2

  # β 氧化：每輪 1 FADH2 (1.5 ATP) + 1 NADH (2.5 ATP)
  beta_atp <- cycles * (1.5 + 2.5)

  # 每個 acetyl-CoA 進 TCA: 3 NADH (7.5) + 1 FADH2 (1.5) + 1 GTP = 10 ATP
  tca_atp <- acetyl_CoA * 10

  # 減去活化代價 2 ATP
  beta_atp + tca_atp - 2
}

fa_atp(16)  # 棕櫚酸 (palmitate, C16) = 106 ATP
fa_atp(18)  # 硬脂酸 (stearate, C18) = 120 ATP

# 與葡萄糖比較（每碳 ATP）
data.frame(
  分子 = c("glucose", "palmitate", "stearate"),
  碳數 = c(6, 16, 18),
  ATP  = c(30, fa_atp(16), fa_atp(18)),
  ATP_per_C = c(30/6, fa_atp(16)/16, fa_atp(18)/18)
)
def fa_atp(n_carbons):
    cycles = n_carbons // 2 - 1
    acetyl_CoA = n_carbons // 2
    beta = cycles * (1.5 + 2.5)
    tca  = acetyl_CoA * 10
    return beta + tca - 2  # 活化耗 2 ATP

for n,name in [(16,"palmitate"),(18,"stearate"),(22,"behenate")]:
    print(f"{name} (C{n}): {fa_atp(n)} ATP, {fa_atp(n)/n:.1f} ATP/C")

# 計算 4 倍葡萄糖能量等效的脂肪酸
import numpy as np
g_per_gram = {"glucose": 30/180, "palmitate": fa_atp(16)/256}
print(f"ATP per gram: {g_per_gram}")
print(f"FA / glucose ratio: {g_per_gram['palmitate']/g_per_gram['glucose']:.2f}")

# 估算飢餓時酮體血液濃度
def ketone_state(insulin_uU, fasting_hrs):
    base = 0.1  # mM
    if insulin_uU < 5:
        return base + 0.5 * np.log1p(fasting_hrs)
    return base
print(f"Day-3 fast ketones: {ketone_state(2, 72):.2f} mM (normal < 0.5)")
