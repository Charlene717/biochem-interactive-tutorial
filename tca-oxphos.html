TCA 循環與氧化磷酸化

代謝中央車站 TCA + Mitchell 化學滲透學說 + ATP synthase 旋轉機制——細胞 90% 的 ATP 在這裡產生。

TCA as metabolism's hub + Mitchell's chemiosmotic theory + ATP synthase's rotary mechanism — where 90% of cellular ATP is made.

PDH

一、PDH 複合體

糖解產物丙酮酸經 MPC (mitochondrial pyruvate carrier) 進入粒線體基質，被 丙酮酸脫氫酶複合體 (PDH) 不可逆地脫羧為乙醯-CoA，連接糖解與 TCA。

PDH 是 60 個次單元的巨大複合體，由 E1（脫羧）、E2（轉移）、E3（再生 FAD）三種酶協作。需要 5 種輔因子：TPP、硫辛酸、CoA、FAD、NAD⁺（記憶法：「Tender Loving Care For Nancy」）。維生素缺乏（B1=TPP）直接影響此酶——腳氣病、Wernicke-Korsakoff 症候群。

PDH 受嚴格調控：高 ATP/NADH/Acetyl-CoA 抑制（產物抑制），磷酸化關閉（PDK），脫磷酸化激活（PDP）。胰島素透過 PDP 激活 PDH，飢餓時 PDK 磷酸化關閉。

Glycolytic pyruvate enters mitochondria via MPC and is irreversibly decarboxylated to acetyl-CoA by the pyruvate dehydrogenase (PDH) complex, connecting glycolysis to TCA.

PDH is a 60-subunit megacomplex with three enzymes — E1 (decarboxylation), E2 (transfer), E3 (FAD regeneration). It needs five cofactors: TPP, lipoic acid, CoA, FAD, NAD⁺. Vitamin deficiency (B1 = TPP) directly impairs PDH — beriberi, Wernicke-Korsakoff.

PDH is tightly regulated: inhibited by high ATP/NADH/acetyl-CoA (product inhibition), turned off by phosphorylation (PDK), turned on by dephosphorylation (PDP). Insulin activates PDH via PDP; fasting turns it off via PDK.

💡
TCA 是「代謝中央車站」：不只氧化能量。中間體可被抽走作合成材料（α-KG → 麩胺酸、OAA → 天門冬胺酸、琥珀醯-CoA → 血基質、檸檬酸 → 脂肪酸合成）。所以需回填反應 (anaplerosis) 補充——主要由丙酮酸羧化酶 (PC) 提供 OAA。 TCA is "metabolic central station": not just oxidation. Intermediates are siphoned for biosynthesis (α-KG → Glu, OAA → Asp, succinyl-CoA → heme, citrate → fatty acids). Anaplerotic reactions refill them — pyruvate carboxylase (PC) → OAA is the main one.

⚠️
Mitchell 化學滲透學說 (1961, 1978 Nobel)：當時被學界激烈反對的「異端」——「呼吸鏈不是直接合成 ATP，而是建立質子梯度，然後 ATP synthase 利用梯度合成 ATP」。今天看來是教科書事實，但當年顛覆了整個生物能量學。 Mitchell's chemiosmotic theory (1961, 1978 Nobel): initially fiercely opposed — "the respiratory chain doesn't directly synthesize ATP; it builds a proton gradient, which ATP synthase uses to make ATP." Now textbook, but revolutionary at the time.
ATP synthase

四、ATP synthase

ATP synthase (Complex V) 是一個真正的奈米馬達。F0 嵌在膜，F1 突出基質。質子流過 F0 的 c 環使其旋轉（每 8–10 個 H⁺ 轉一圈，依生物物種而異）；γ 軸旋轉迫使 F1 的三個 β 次單元依序通過 O → L → T → O 三構象，使 ADP+Pi 在 T 構象合成為 ATP 並釋放。Boyer 與 Walker 因此獲 1997 Nobel。

P/O 比例：每個 NADH 約產 2.5 ATP；每個 FADH₂ 約產 1.5 ATP。每分子葡萄糖完全氧化產 30–32 ATP（過去課本說 36–38，2000 後修正）。

ATP synthase (Complex V) is a true nanomotor. F0 sits in the membrane, F1 protrudes into the matrix. Protons flowing through F0's c-ring rotate it (8–10 H⁺ per turn depending on species); rotation of the γ shaft cycles the three β subunits through O → L → T → O conformations, synthesizing and releasing ATP at T. Boyer & Walker won the 1997 Nobel.

P/O ratio: ~2.5 ATP per NADH; ~1.5 ATP per FADH₂. Full glucose oxidation yields 30–32 ATP (older textbooks said 36–38; revised after 2000).

ROS / 棕色脂肪

五、ROS 與棕色脂肪

ROS 副產物：~1–2% 的 O₂ 在 ETC 中變成 O₂·⁻、H₂O₂、·OH。細胞用 SOD（Cu/Zn 細胞質、Mn 粒線體）、catalase、GPx、TXN/PRX 系統清除。失衡 → 氧化壓力 → 老化、神經退化、癌。

UCP1（thermogenin）：棕色脂肪細胞特有的「解偶聯蛋白」——允許 H⁺ 漏回基質而不經 ATP synthase，將電子傳遞鏈的能量直接變熱。嬰兒、冬眠動物用此維持體溫。2021 後成為「可激活棕色脂肪」抗肥胖藥物標靶。

ROS by-products: ~1–2% of O₂ becomes O₂·⁻, H₂O₂, ·OH in the ETC. Cells use SOD (Cu/Zn cytosolic, Mn mitochondrial), catalase, GPx, TXN/PRX systems to clear them. Imbalance → oxidative stress → aging, neurodegeneration, cancer.

UCP1 (thermogenin): brown-fat-specific "uncoupling protein" — lets H⁺ leak back to the matrix bypassing ATP synthase, dissipating ETC energy as heat. Infants and hibernating animals use it for thermoregulation. Since 2021, "activatable brown fat" has become a drug target for obesity.

OCR 分析

# Seahorse XF Mito Stress Test 分析
library(ggplot2)

ocr <- data.frame(
  time   = c(1:12),
  rate   = c(100,105,95, 120,125,115, 30,28,32, 180,175,15),
  treat  = rep(c("basal","oligomycin","FCCP","rot+AA"), each=3)
)

# 計算關鍵參數
basal    <- mean(ocr$rate[ocr$treat=="basal"])
oligo    <- mean(ocr$rate[ocr$treat=="oligomycin"])
fccp     <- mean(ocr$rate[ocr$treat=="FCCP"])
non_mito <- mean(ocr$rate[ocr$treat=="rot+AA"])

atp_linked <- basal - oligo                    # ATP-linked OCR
max_resp   <- fccp - non_mito                  # 最大呼吸
reserve    <- max_resp - (basal - non_mito)    # 備用呼吸量
proton_leak<- oligo - non_mito                 # 質子漏 (uncoupling)

cat("ATP-linked:", atp_linked, "\n")
cat("Max:", max_resp, "\nReserve:", reserve, "\nLeak:", proton_leak, "\n")
import pandas as pd
import matplotlib.pyplot as plt

# Seahorse data
df = pd.DataFrame({
    "time": range(12),
    "rate": [100,105,95,  120,125,115,  30,28,32,  180,175,15],
    "treat": ["basal"]*3 + ["oligo"]*3 + ["FCCP"]*3 + ["rot_AA"]*3
})

basal = df[df.treat=="basal"].rate.mean()
oligo = df[df.treat=="oligo"].rate.mean()
fccp  = df[df.treat=="FCCP"].rate.mean()
nonmt = df[df.treat=="rot_AA"].rate.mean()

print(f"ATP-linked OCR  = {basal-oligo:.1f}")
print(f"Max respiration = {fccp-nonmt:.1f}")
print(f"Reserve         = {fccp-basal:.1f}")
print(f"Proton leak     = {oligo-nonmt:.1f}")

# 評估：ATP-linked OCR < 50% 表示粒線體功能受損
if (basal - oligo) / basal < 0.5:
    print("⚠️ Mitochondrial dysfunction suspected")
