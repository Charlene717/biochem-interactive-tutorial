CHAPTER 6 / 18 · BLOCK B

酶催化機制

酶如何把反應速率加快 10⁶–10¹⁷ 倍？六種催化策略加上 2024 新觀點「寬廣過渡態組合」。

How do enzymes accelerate reactions 10⁶–10¹⁷-fold? Six catalytic strategies plus the 2024 view of "broad transition-state ensembles."

概覽

核心問題

酶不改變反應的熱力學（ΔG 不變），只改變動力學——降低活化能 (Eₐ)。對甲基化反應的酶 catechol-O-methyltransferase 速率加快約 10¹⁷ 倍。要解釋這個誇張的數字，需要多種催化策略共同作用。

EC 編號（Enzyme Commission）以六大類分類：1. Oxidoreductases、2. Transferases、3. Hydrolases、4. Lyases、5. Isomerases、6. Ligases。2018 後新增 7. Translocases。

Enzymes don't change reaction thermodynamics (ΔG is unchanged), only kinetics — they lower activation energy (Eₐ). Catechol-O-methyltransferase accelerates its reaction ~10¹⁷-fold. Explaining this requires multiple cooperating strategies.

EC numbering classifies enzymes into six classes: 1. Oxidoreductases, 2. Transferases, 3. Hydrolases, 4. Lyases, 5. Isomerases, 6. Ligases; class 7. Translocases was added in 2018.

六種策略

一、六種催化策略

🎯

① 過渡態穩定化

核心策略。酶活位點對過渡態 (TS) 的親和力比對基質高，相對降低 Eₐ。Pauling 1948 提出。過渡態類似物 (transition-state analogs) 因此成為最強的酶抑制劑（如 statins）。

The core strategy. Active sites bind the transition state more tightly than the substrate, lowering Eₐ. Pauling (1948). Transition-state analogs are therefore the strongest enzyme inhibitors (e.g. statins).

↕️

② 酸鹼催化

側鏈作為質子供體/受體加速反應。His (pKa 6.0) 是最常見的酸鹼催化殘基（生理 pH 下半質子化）。例：RNase A 用兩個 His（His12 作為酸、His119 作為鹼）。

Side chains as proton donor/acceptor. His (pKa 6.0) is the most common acid-base residue (half-protonated at pH 7). Example: RNase A uses two His (His12 acid, His119 base).

🔗

③ 共價催化

酶與基質形成短暫共價中間體，再分解。絲胺酸蛋白酶（chymotrypsin, trypsin, elastase）的 Ser-His-Asp 催化三聯體是經典案例：Ser-OH 攻擊肽鍵 C，形成醯基-酶中間體。

Enzyme forms a transient covalent intermediate with substrate. Serine proteases (chymotrypsin, trypsin, elastase) Ser-His-Asp catalytic triad is the classic case: Ser-OH attacks the peptide carbonyl, forming an acyl-enzyme intermediate.

⚛️

④ 金屬離子催化

金屬離子穩定負電荷、極化鍵結、執行 redox。例：羧肽酶 A（Zn²⁺）、碳酸酐酶（Zn²⁺）、超氧岐化酶（Cu, Zn）、細胞色素（Fe）。約 1/3 酶為金屬酶。

Metals stabilize negative charges, polarize bonds, run redox. Examples: carboxypeptidase A (Zn²⁺), carbonic anhydrase (Zn²⁺), SOD (Cu, Zn), cytochromes (Fe). ~1/3 of enzymes are metalloenzymes.

📐

⑤ 近接與定向

酶把基質拉到正確位置與方向。光靠近接就可加速 10⁴–10⁸ 倍。雙基質酶（如轉胺酶）特別重要——兩個基質排列在毫米距離但 ångström 精度方向。

Enzymes hold substrates in the right place and orientation. Proximity alone can accelerate reactions 10⁴–10⁸-fold. Especially critical for bisubstrate enzymes (e.g. transaminases).

⛏️

⑥ 基質形變

酶結合時迫使基質扭曲、靠近過渡態構象（Lysozyme 把 NAG-NAM 醣鏈扭轉為半椅式）。Koshland 1958 提出，後由結構生物學證實。

Enzyme binding distorts the substrate toward the transition-state geometry (lysozyme bends NAG-NAM sugar to half-chair). Koshland's 1958 induced-fit model, later confirmed structurally.

⚠️
2024 新觀點（eLife 2024）：「寬廣過渡態組合」(broad TS ensemble)。傳統認為過渡態是單一結構；但結合 NMR 與 MD 模擬顯示，過渡態其實是一群能量相似的構象集合。這解釋了酶為何能耐多種突變、為何同一活位點可演化成不同特異性——「演化只需找一個寬鬆的過渡態漏斗」。 2024 perspective (eLife 2024): "broad transition-state ensembles." The classical view holds transition state as a single structure; but NMR + MD show TS is actually a cluster of energetically equivalent conformations. This explains why enzymes tolerate mutations and why one active site can evolve into different specificities — "evolution only needs to find a loose TS funnel."
經典案例

二、絲胺酸蛋白酶

基質結合

肽鍵基質進入結合口袋，S1 pocket 決定特異性：chymotrypsin 大且疏水（喜歡 Phe/Trp/Tyr），trypsin 帶 Asp（喜歡 Lys/Arg），elastase 淺（喜歡小殘基如 Ala）。

Peptide substrate enters; S1 pocket dictates specificity: chymotrypsin large/hydrophobic (Phe/Trp/Tyr), trypsin has Asp (Lys/Arg), elastase shallow (Ala/Gly).

親核攻擊

His57 從 Ser195-OH 拉走質子；Ser195 烷氧基攻擊肽鍵 C=O，形成四面體中間體。Asp102 與 His57 透過氫鍵穩定電荷。

His57 abstracts a proton from Ser195-OH; the Ser195 alkoxide attacks the peptide carbonyl, forming a tetrahedral intermediate. Asp102 stabilizes His57 charge via H-bond.

醯基-酶中間體

肽鍵 C-N 斷裂，N 端離開（His57 將質子轉給離去 NH）。Ser195 與 C 端形成共價醯基-酶。

The C-N bond breaks, releasing the N-terminal fragment (His57 protonates the leaving NH). Ser195 retains the C-terminal as an acyl-enzyme.

水解再生

水分子由 His57 活化後攻擊醯基-酶，形成第二個四面體中間體，最終釋放 C 端片段並再生 Ser-OH。整個過程酶毫髮無損。

Water (activated by His57) attacks the acyl-enzyme, forming a second tetrahedral intermediate; the C-terminal fragment is released and Ser-OH is regenerated. The enzyme emerges unchanged.

三、判定機制

🌳 從實驗線索推斷

Q1:
pH-rate 曲線顯示 pKa ≈ 6 處有過渡？→ 牽涉 His 殘基（酸鹼催化）。
Q2:
金屬螯合劑（EDTA）抑制？→ 金屬酶（Zn²⁺、Mg²⁺、Mn²⁺...）。
Q3:
能用 DFP 或 iodoacetamide 不可逆抑制？→ DFP 標 Ser（絲胺酸蛋白酶）、iodoacetamide 標 Cys（半胱胺酸蛋白酶）。
Q4:
反應中可捕獲共價中間體？→ 共價催化（如醯基-酶、希夫鹼、麩胱甘肽中間體）。
Q5:
結構顯示基質扭曲？→ 誘導擬合 + 基質形變（如 lysozyme）。
Q1:
pH-rate curve shows transition near pKa ≈ 6? → Involves His (acid-base).
Q2:
Metal chelators (EDTA) inhibit? → Metalloenzyme.
Q3:
Irreversibly inhibited by DFP or iodoacetamide? → DFP labels Ser (serine protease); iodoacetamide labels Cys (cysteine protease).
Q4:
Covalent intermediate trappable? → Covalent catalysis (acyl-enzyme, Schiff base, glutathione intermediates).
Q5:
Structure shows substrate distortion? → Induced fit + substrate strain (e.g. lysozyme).

活性位點保守性

library(bio3d)

# 對絲胺酸蛋白酶家族做多重序列比對
seqs <- read.fasta("serine_proteases.fa")
aln  <- seqaln(seqs)

# 計算每個位置的保守性（用 entropy）
ent <- entropy(aln)$H

# 過濾保守位置（entropy < 0.5）
conserved <- which(ent < 0.5)
cat("Conserved positions:", conserved, "\n")

# 在結構上標出催化三聯體
pdb <- read.pdb("1AKS")  # α-chymotrypsin
triad <- pdb$atom[pdb$atom$resno %in% c(57, 102, 195) & pdb$atom$elety == "CA", ]
triad[, c("resno", "resid")]  # 應顯示 His-57, Asp-102, Ser-195
from Bio import AlignIO
import numpy as np

aln = AlignIO.read("serine_proteases.aln", "clustal")
n_seq = len(aln); L = aln.get_alignment_length()

# Shannon entropy per column
def entropy(col):
    counts = {}
    for aa in col:
        counts[aa] = counts.get(aa, 0) + 1
    H = 0
    for c in counts.values():
        p = c / len(col)
        H -= p * np.log2(p)
    return H

ent = [entropy(aln[:, i]) for i in range(L)]
conserved = [i for i,h in enumerate(ent) if h < 0.3]
print(f"Conserved columns: {conserved[:20]}...")

# 反應速率：Arrhenius
def k_rate(Ea, T=310, A=1e13):
    R = 8.314  # J/(mol·K)
    return A * np.exp(-Ea * 1000 / (R * T))

# 加速倍數
fold = k_rate(40) / k_rate(80)  # Ea 從 80 降到 40
print(f"Acceleration: {fold:.2e}-fold")
